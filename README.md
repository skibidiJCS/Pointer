# Pointer

Pointer turns an Apple Watch into a trackpad for Mac

## Setup

1. open `Pointer.xcodeproj` in Xcode 16 or later
2. select your development team for both app targets
3. run `Pointer` on Mac and `Pointer Watch` on a paired Apple Watch
4. allow local network access on both devices
5. click **Enable Cursor Control** on Mac and grant Accessibility access

Both devices must be on the same local network
