# Pointer

Pointer turns an Apple Watch into a wireless trackpad for a Mac.

## Setup

1. Open `Pointer.xcodeproj` in Xcode 16 or later.
2. Select your development team for both app targets.
3. Run `Pointer` on the Mac and `Pointer Watch` on a paired Apple Watch.
4. Allow local network access on both devices.
5. Click **Enable Cursor Control** on the Mac and grant Accessibility access.

Both devices must be on the same local network.
